## crime_analyser
This project includes the understanding and visualization of Indian crime data from 2021-2023 of all states.

# platform used
MS Excel
Python
Power BI

# categories in which we monitor the crime rates
Cyber Crime  
Economic Crime  
Crime Against Women  
Narcotics / Drug Related Crime  
Violent Crime

*Also, it shows the total number of IPL and SLL crimes.

# KPI & Visuals used
Map Visual
Clustered Column Chart
Line Chart
Slicer
KPI Cards
